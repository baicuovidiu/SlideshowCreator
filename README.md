# SLIDESHOW CREATOR - MVP 0.1.4

NOU în 0.1.4:
- Import direct prin click în zona mare IMPORTĂ FOTO / VIDEO.
- Drag & drop de fișiere în aplicație.
- Thumbnail-uri vizibile în MEDIA și TIMELINE.
- Acceptare RAW: ARW, CR2, CR3, NEF, NRW, ORF, RW2, RAF, DNG, PEF, SRW + HEIC/HEIF (unde Windows/WIC poate decoda).
- Extindere video: FFmpeg/FFprobe pentru numeroase containere și codecuri.
- Panourile MEDIA / PREVIEW / PROPRIETĂȚI și TIMELINE pot fi redimensionate manual.
- Grupuri de comenzi diferențiate vizual prin culori.
- Export MP4 reparat: citirea FFmpeg nu mai poate bloca interfața din cauza bufferului stderr.
- Bară de progres și stare detaliată la export.
- Mesaje de eroare mai clare.

Build-ul oficial se face automat pe Windows prin GitHub Actions și produce `SlideshowCreator-Setup-0.1.4.exe`.
